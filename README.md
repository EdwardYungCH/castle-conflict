# Castle Conflict（1.85 網頁移植 + 六王國擴充）

已下架的 iPhone 遊戲 **Castle Conflict**（Broken Kings，2010，v1.85）的網頁版。這是單一 HTML 檔，內含原版的全部圖片與音效，可離線遊玩。

▶ **遊玩：** 用瀏覽器開啟 `index.html`。開啟 GitHub Pages 後，也可以直接在網上玩。

## 內容
- **主選單：** Campaign、Quick Play、Multi-Player、About us（製作人員名單）、Preview、Survey。
- **Quick Play：**
  - Custom 設定：難度、局長、樹木生長、回血道具。
  - 中途退出會存檔，下次可選 Continue 繼續。
  - 勝利後可提升難度；Hard 難度勝利可得獎盃，獎盃按鈕點三下會召喚粉紅獨角獸。
- **Campaign：**
  - 3 個存檔槽。
  - 中世紀、埃及、北方（v2.0）、東方（v2.3）、地底（v2.4）和天空（v2.5）六張世界地圖，共 103 座城堡；全部征服後有結局畫面。
  - 科技商店、軍營換兵、外觀選擇、成就獎勵、征服畫面（含 Rank）。
- **戰鬥：**
  - 33 種原版兵種，加上北方、東方、地底、天空各 5 種新兵種。
  - 城堡升級外觀。
  - 雲、鳥、水光等景物。
  - 埃及地圖的高樹和蟻獅。
  - 快速對戰 AI，以及原版的戰役 AI（fitness 評分）。
- **Multi-Player：** 原版需要藍牙或 WiFi 連線；這裡改為同一裝置雙人對戰，紅方按鈕在畫面底部。

## 操作
- 觸控或滑鼠操作。
- 鍵盤：
  - 1–9：出兵
  - 空白鍵：暫停
  - Esc：退出
  - Q–O：雙人模式中紅方出兵

## 與原版的差異
- Multi-Player 改為同機雙人對戰。
- Preview、Survey 改為離線版本。
- 載入畫面加了「Touch to start」提示，因為瀏覽器要先觸控一次才能播放聲音。
- 刻意保留原版的程式錯誤：Hard 難度只要勝利就會得到獎盃。
- Egyptian Temple 外觀不會解鎖的原版錯誤，已在 v2.0 修正（見下文）。

## v2.0 擴充（非官方續作內容）
原版更新到 1.85 就停止了。埃及地圖最後那艘船只會說「Nothing here yet...」。v2.0 讓它真的開往新地方。

**補完原版**
- 征服神殿城堡後，Egyptian Temple 外觀會正確解鎖；舊存檔已征服的會自動補發。
- Temple 成為真正的升級：在 Temple Units 頁購買（11 tech points），Temple 兵種需要它；城堡前會出現方尖碑。
- Solar 免費自動獲得，城堡上方會出現太陽圓盤。

**第三王國：北方王國（Northern Realm）**
- 新世界地圖：16 座維京領主（Jarl）城堡（id 39–54），最後是 Hrimthur the Frost King。
- 新外觀「Northern Fortress」：到達北方時自動解鎖。
- 新升級 Longhouse，以及 5 個新兵種：

| 兵種 | 金幣 | 特點 |
|---|---|---|
| Wolf Pack | 35 | 一次放出 3 隻快速的狼 |
| Berserker | 40 | 每殺一個敵人就更快更強（最多 3 次） |
| Dragon Longship | 60 | 衝鋒，被擊毀或撞城後跳出 3 個士兵 |
| Rune Priest | 45 | 施法凍結所有敵方地面單位 3 秒 |
| Frost Giant | 70 | 很慢，但力量 6、不怕弓箭和炸彈，暴風雪中不減速 |

- 兩個場景機關：**暴風雪**（每隔一段時間颳雪 6 秒，地面單位減速一半）和**薄冰**（戰場中央的冰面，騎兵、重騎兵、攻城槌和石像有機會掉進冰洞）。
- 雙人模式新增 4 個北方關卡。
- 美術全部由原版像素圖改色、拼合而成，產生腳本在 `tools/`（`python tools/build_art.py`）。

## 新介面（v3.0）
主選單左下角的「New UI」木牌可以切到新介面，新介面右下角的「Classic UI」切回經典介面；設定會記住，存檔兩邊共用。新介面全部用原版的石板、橫幅和點陣字做，只是排版和操作現代化：

- **戰鬥 HUD**：闊屏手機（19.5:9）上，出兵按鈕移到左邊兩欄，暫停／加速／雙倍收入／說明／退出在右邊一欄，戰場完全不被遮；2:1 屏幕左右各一欄；3:2 屏幕維持頂部一排。買不起的兵變暗、價錢變紅；血條上顯示數字；頂部顯示城堡名和時間。
- **長按兵種看說明卡**（力量、速度、攻城傷害、特性），看的時候遊戲暫停。輕按才出兵。
- **2x 加速**按鈕。
- **暫停選單**：繼續／重新開始／退出，音樂和音效音量分開調（會記住）。
- **新機關說明卡**：第一次遇到高樹、蟻獅、暴風雪、薄冰、霧、吊橋、岩漿、地道、浮島缺口、強風時，開戰前先說明一次。
- **戰鬥回饋**：城堡受傷彈出傷害數字，單位交戰時有火花，戰役開戰前有 VS 橫幅。
- **一頁式主選單**：「繼續戰役」顯示上次存檔、所在王國、城堡進度和科技點；快速對戰、無盡、雙人、紀錄各帶自己的成績。
- **世界地圖**：可攻打的城堡上方顯示難度星級和機關圖示，頂部顯示王國進度；商店／軍隊／外觀按鈕維持原版。
- **商店**：每個兵種一行，力量和速度用數值條並排比較，整行都可以點。

## 世界地圖縮放（v3.0）
經典和新介面都支援：雙指縮放、滑鼠滾輪；新介面另有 +／− 按鈕。範圍從「整張地圖」到 2 倍，縮放位置會記在存檔。

## 天空王國（v2.5，最終章）
地底最深處的熱氣球升上雲端。新地圖是一串浮島，16 座執政官（Archon）的尖塔，最終 Boss 是 Seraphiel the Last，他會派出六個王國的兵種。征服全部六個王國後會進入結局畫面，列出六個王國的戰績和累積統計。

- **浮島缺口**：島與島之間沒有連續的地面。每場戰鬥中央有 1 個缺口，或左右對稱的 2 個（位置每場不同）。慢的地面單位會停在崖邊，速度 60 以上的（騎兵、狗、攻城槌等）煞不住會直接掉下去。空軍、地道單位和 Angel Guard 不受影響。
- **雲橋**：Cloud Bridge Builder 走到缺口前建一座雲橋，維持 20 秒，兩邊的單位都能過。
- **強風**：每隔一段時間颳風 4 秒，把所有飛船吹向同一邊（Sky Battleship 只會被吹動一點）。
- **新外觀「Sky Spire」**，新升級 Observatory 和 5 個兵種：

| 兵種 | 金幣 | 特點 |
|---|---|---|
| Cloud Bridge Builder | 20 | 在前方第一個缺口建雲橋（20 秒），然後回家 |
| Griffin Rider | 55 | 飛行單位，會俯衝擊殺下方的弱小地面單位（力量 2 以下） |
| Thundercloud Mage | 50 | 施法召喚閃電，擊殺戰場上最強的一個敵人（力量 6 以下，地道單位除外） |
| Angel Guard | 45 | 力量 3，能飛越缺口；戰死後 1 秒內復活一次 |
| Sky Battleship | 90 | 力量 5 的重型轟炸飛船，附砲塔會自動射擊附近的敵方飛船 |

- 新增成就：Shogun、Deep Thane、Sky Lord、World Conqueror。
- 雙人模式新增 4 個天空關卡；無盡模式第 31 波起進入天空。

## 地底王國（v2.4）
東方火山口的洞穴通往地底。新地圖 16 座矮人領主（Thane）要塞，最終 Boss 是 Durgan the Deep。這個王國改變了戰場結構：

- **地道**：地面下方多了一條地道，從你的城堡地窖通到敵方地窖。地道單位和地面單位互不相干，炮彈、箭也打不到地道。
- **礦脈**：地道裡會長出水晶礦脈，礦工挖了帶回 30 金。
- **岩漿噴發**：每隔一段時間戰場某處先發紅 1 秒，然後噴出岩漿，附近的地面單位即死（空軍、地道單位、熔岩魔像不受影響）。
- **新外觀「Dwarven Hold」**，新升級 Forge 和 5 個兵種：

| 兵種 | 金幣 | 特點 |
|---|---|---|
| Miner | 10 | 走地道挖礦，每次 30 金 |
| Burrower | 35 | 走地道，繞過地面所有敵人直接咬城（20 傷害） |
| Bat Swarm | 30 | 3 隻極快的蝙蝠，專門騷擾飛船 |
| Dwarf Engineer | 40 | 走到地道中段封住地道 20 秒，敵方地道單位過不去；或拆掉敵方的封鎖 |
| Lava Golem | 75 | 力量 5，死後留下一灘岩漿 5 秒，敵方地面單位踩到即死 |

## 東方王國（v2.3）
北方最後那艘船開往東方。新地圖 16 座將軍（Shogun）城堡，最終 Boss 是 Takeda the Unseen，他的戰場永遠起霧。

- **新外觀「Eastern Castle」**：到達東方時自動解鎖。
- **新升級 Dojo 與 5 個兵種：**

| 兵種 | 金幣 | 特點 |
|---|---|---|
| Ninja | 25 | 隱身，敵人看不見也打不到，直到他偷到金幣（偷 20） |
| Samurai | 45 | 力量 3，打贏弱兵不會停下，一路斬過去 |
| Fan Dancer | 40 | 施法把所有敵方飛船吹退 100 像素 |
| Crane Caster | 50 | 放出 3 隻紙鶴，紙鶴會擋下箭、火球和炮彈 |
| Trebuchet | 65 | 走到戰場前段停下，每 3 秒向敵城投石（20 傷害）；任何敵人碰到就被毀 |

- **場景機關：** **濃霧**（定時起霧 8 秒，戰場中段看不到單位，電腦 AI 也看不到）和**吊橋**（戰場中央的橋。攻城槌、巨人、龍船經過或炮彈、炸彈落在橋上會損壞它；壞了之後地面單位過橋只有三分之一速度，15 秒後自動修好）。
- 雙人模式新增 4 個東方關卡；無盡模式第 19 波起進入東方。

## 無盡模式與紀錄（v2.2）
- **Endless（無盡模式）**：在 Quick Play 選單。守住你的城堡，敵方城堡每被攻破一次就換上更強的一波：兵種越來越多、AI 越來越快、血量越來越高，每 6 波換一個王國（中世紀 → 埃及 → 北方 → 東方 → 地底 → 天空）。每清一波回血 20、加金幣。你的城堡倒下時結束，記錄最佳波數。
- **Records（紀錄）**：主選單左下角的獎盃圖示。顯示累積統計（戰鬥數、擊殺、伐木、偷金等）和 20 個成就。

## 寬屏手機（v2.1）
遊戲世界維持原版 480×320，不改變戰場距離和平衡。在 iPhone 16 Pro Max 這類 19.5:9 的手機上，畫面會延伸到兩側填滿整個屏幕：兩側顯示背景的鏡像延伸，世界地圖則直接顯示更多地圖。橫向時畫面會延伸到動態島下方，但遊戲本體都在安全區內。

## iOS 版（Capacitor 原生包裝）
`index.html` 用 Capacitor 包成原生 iOS App，由 GitHub Actions 的 macOS 機器自動編譯（`.github/workflows/ios.yml`），不需要自己有 Mac。每次推上 main 都會重新編譯，產出未簽名的 `CastleConflict-unsigned.ipa`，放在 Release **ios-latest**：

https://github.com/EdwardYungCH/castle-conflict/releases/tag/ios-latest

因為沒有付費開發者帳號，要用自己的 Apple ID 簽名後側載。Windows 上用 **Sideloadly** 最簡單：

1. 在 iPhone 開啟開發者模式：設定 → 隱私權與安全性 → 開發者模式（開了會重開機）。
2. Windows 安裝 iTunes（要從 apple.com 下載的版本，不要 Microsoft Store 版），再安裝 Sideloadly（https://sideloadly.io）。
3. iPhone 用 USB 線接電腦，手機上按「信任」。
4. 開 Sideloadly，把 `CastleConflict-unsigned.ipa` 拖進去，填 Apple ID，按 Start，輸入密碼（有雙重認證會問驗證碼）。
5. 裝好後在 iPhone：設定 → 一般 → VPN 與裝置管理 → 信任你的 Apple ID。

免費 Apple ID 簽的 App **7 天到期**（最多同時 3 個），到期後用 Sideloadly 再裝一次就好，存檔不會消失。AltStore 也可以，做法相同。

iOS 版的存檔和 PWA（加到主畫面的網頁版）是分開的。橫向全螢幕，沒有狀態列。本機重建：`npm install && npm run build && npm run ios:add`，之後在 Xcode 開 `ios/App/App.xcworkspace`。

## 加到 iPhone 主畫面（PWA）
1. 在 Safari 開啟遊戲網址。
2. 分享 → 加入主畫面。
3. 從主畫面圖示開啟，即為全螢幕、可離線。更新後重新開啟兩次即可載入新版。
